# Personal Portfolio Website

A small beginner-friendly portfolio website made with plain HTML and CSS.

## Features

- Home, About, Skills, Projects and Contact sections
- Navigation links that move to each section
- Simple project cards and skill labels
- Responsive layout for smaller screens
- No JavaScript, frameworks or external libraries

## Project files

- `index.html` — contains the page content and sections.
- `style.css` — controls colours, spacing, layout, typography and the mobile layout.
- `README.md` — explains the project and how to run it.

## How to run the project

### Option 1: Open it directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. It will open in your web browser.

### Option 2: Use Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension (optional).
3. Right-click `index.html`.
4. Select **Open with Live Server**.

No installation or build command is required.

## Personalise the page

1. Open `index.html`.
2. Replace `Your Name` with your own name.
3. Update the About Me paragraph and skills.
4. Replace `your.email@example.com` with your email address.
5. Save the file and refresh the browser.
